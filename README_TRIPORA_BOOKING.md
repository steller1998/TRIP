# Tripora – booking interaction update

This package fixes the broken JavaScript filename and adds working service booking panels for:

- Flight Booking
- Train Booking
- Hotel Booking
- Holiday Packages

Each service button now opens a professional form. Submitting the form prepares a structured WhatsApp enquiry to the Tripora travel desk.

## Important
The forms are functional, but **live flight/hotel inventory is not connected yet**. Do not advertise live prices or instant ticket/room confirmation until the TBO/API credentials are approved and connected.

## Deploy to GitHub Pages
Replace the files in the GitHub repository with the contents of this folder, commit, and push. GitHub Pages will publish the updated site using the existing workflow.
